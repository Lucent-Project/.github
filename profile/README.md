# Lucent Project

Lucent is an AI assistant app for Android and Windows — chat, notes, tasks, terminal, and more, wrapped in a liquid-glass interface.

## Repositories

- **[Lucent](https://github.com/Lucent-Project/Lucent)** — the main app, built with Kotlin Multiplatform
- **[lucentapp](https://github.com/Lucent-Project/lucentapp)** — the official website and download mirror
- **[lucent-assets](https://github.com/Lucent-Project/lucent-assets)** — large build-time assets, fetched during builds so the main repo stays lean

## Download

Get the latest stable build: https://lucent-project.github.io/lucentapp/
